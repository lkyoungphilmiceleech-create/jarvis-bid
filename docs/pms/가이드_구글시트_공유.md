# 법인카드 공용 시트 공유 가이드 (MICELEECH PMS)

PMS가 법인카드 시트를 **읽기 전용**으로 가져오려면, PMS 전용 '서비스 계정'(로봇 계정)에 시트를 공유해야 합니다.
시트를 '링크가 있는 모든 사용자'로 공개하는 방식은 금액·거래처 정보가 외부에 노출될 수 있으므로 **사용하지 않습니다.**

## 1단계. 서비스 계정 만들기 (최초 1회, 약 10분)

1. 회사 구글 계정으로 [Google Cloud 콘솔](https://console.cloud.google.com/) 접속
2. 상단 프로젝트 선택 → **새 프로젝트** → 이름 `miceleech-pms` → 만들기
3. 좌측 메뉴 **API 및 서비스 → 라이브러리**에서 `Google Sheets API` 검색 → **사용**
   (드라이브 색인용으로 `Google Drive API`도 같은 방법으로 **사용**)
4. **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → 서비스 계정**
   - 이름: `pms-sheet-reader` → 완료 (역할은 지정하지 않아도 됩니다)
5. 만들어진 서비스 계정을 클릭 → **키 → 키 추가 → 새 키 만들기 → JSON** → 파일이 내려받아집니다
6. 서비스 계정 이메일(예: `pms-sheet-reader@miceleech-pms.iam.gserviceaccount.com`)을 복사해 둡니다

> ⚠ JSON 키 파일은 **비밀번호와 같습니다.** 채팅·메일·메신저로 보내지 마세요.
> 저장 위치: GitHub 저장소 **Settings → Secrets and variables → Actions → New repository secret**
> 이름 `GOOGLE_SA_KEY`, 값은 JSON 파일 내용 전체 (기존 `DATA_GO_KR_KEY`와 같은 방식)

## 2단계. 시트 공유 (시트마다)

1. 법인카드 공용 스프레드시트 열기 → 우측 상단 **공유**
2. 6단계에서 복사한 서비스 계정 이메일 입력 → 권한 **뷰어** → '이메일 알림' 해제 → 공유
3. 브라우저 주소창의 시트 URL을 PMS 담당(Claude)에게 전달
   - URL만 전달하면 되며, 서비스 계정에 공유되지 않은 사용자는 URL로도 열 수 없습니다

## 3단계. PMS 설정 (Claude 작업)

- 탭 이름 ↔ 카드 소지자 매핑, 프로젝트 표기 ↔ PMS 프로젝트 별칭 등록
- 시험 가져오기 → 행 단위 오류·미분류 보고 → 수정 → 정기 동기화 설정

## 공유 해제

시트 **공유**에서 서비스 계정을 삭제하면 즉시 읽기가 중단됩니다.
