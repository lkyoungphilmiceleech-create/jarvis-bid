# 운영 환경 준비 가이드 (MICELEECH PMS)

체험 모드를 실제 데이터 모드로 바꾸는 절차입니다. 모든 계정은 **회사 명의 이메일**로 만듭니다.
비밀 값(키·비밀번호)은 채팅으로 보내지 말고, 아래에 적힌 설정 화면에만 입력합니다.

## 1. Supabase (데이터베이스·로그인) — 약 15분

1. [supabase.com](https://supabase.com) → 회사 이메일로 가입 → **New project**
   - Name: `miceleech-pms` / Region: **Northeast Asia (Seoul)** / DB 비밀번호: 강력하게 생성 후 사내 보관
2. 좌측 **SQL Editor** → New query → 저장소의 파일 내용을 **순서대로** 붙여넣고 Run
   1. `pms/db/migrations/0001_init.sql`
   2. `pms/db/migrations/0002_signup_fx_cardsheet.sql`
   3. `pms/db/migrations/0003_budget_versions.sql`
   4. `pms/db/migrations/0004_contract_split_budget_approval.sql`
   5. `pms/db/migrations/0005_issue_close_notifications.sql`
   6. `pms/db/seed/pilot_kocca.sql` (첫 줄 `\set ON_ERROR_STOP on` 은 지우고 실행)
3. **Project Settings → API** 에서 두 값을 확인 (다음 단계에서 입력)
   - Project URL → `NEXT_PUBLIC_SUPABASE_URL`
   - anon public key → `NEXT_PUBLIC_SUPABASE_ANON_KEY` (공개용 키, 권한은 DB 규칙이 강제)
   - service_role key → `SUPABASE_SERVICE_ROLE_KEY` (**알림 발송 서버 작업 전용 비밀 키** — 2단계 Vercel 환경변수에만 입력, 그 외 어디에도 붙여넣지 않음)

## 2. Vercel (웹앱 호스팅) — 약 10분

1. [vercel.com](https://vercel.com) → GitHub 계정으로 가입 → **Add New → Project** → `jarvis-bid` 저장소 선택
2. **Root Directory**: `pms` / Framework: Next.js (자동 인식)
3. **Environment Variables** 입력 → Deploy

| 이름 | 값 |
|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | 1-3 Project URL |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | 1-3 anon public key |
| `SUPABASE_SERVICE_ROLE_KEY` | 1-3 service_role key (비밀) |
| `APP_URL` | `https://pms.miceleech.com` |
| `CRON_SECRET` | 임의의 긴 문자열(비밀번호 생성기로 32자 이상) |
| `SMTP_HOST` `SMTP_PORT` `SMTP_USER` `SMTP_PASS` `SMTP_FROM` | 5단계(이메일 알림) |
| `KAKAOWORK_BOT_KEY` | 6단계(카카오워크 알림) |

4. **도메인 연결** (`pms.miceleech.com`)
   - Vercel 프로젝트 **Settings → Domains → Add** → `pms.miceleech.com` 입력
   - Vercel이 보여주는 DNS 레코드(보통 `pms` 이름의 CNAME)를 `miceleech.com` 도메인 관리 업체의 DNS 설정에 그대로 추가
   - 연결 확인(수 분~수 시간) 후 HTTPS 인증서는 Vercel이 자동 발급
5. Supabase **Authentication → URL Configuration → Site URL** 에 `https://pms.miceleech.com` 입력

## 3. 최초 관리자 지정

1. 배포된 주소에서 **가입 신청** → 확인 메일 클릭 → 로그인하면 '승인 대기' 화면
2. Supabase **SQL Editor** 에서 아래 실행 (이메일만 본인 것으로 교체)

```sql
update profiles set role = 'admin', active = true where email = '가입한이메일';
update projects set pm_id = (select id from profiles where email = '가입한이메일')
 where name = 'KOCCA 해외마켓' or parent_id in (select id from projects where name = 'KOCCA 해외마켓');
```

3. 다시 로그인 → **경영 대시보드**가 보이면 완료. 이후 직원 가입은 관리자 승인으로 처리

## 4. 법인카드 시트

`가이드_구글시트_공유.md` 참고 (서비스 계정 → 시트 뷰어 공유 → URL 전달)

## 5. 이메일 알림 (메일플러그 SMTP)

1. 발송 전용 계정 생성 권장 (예: `pms@miceleech.com`) — 개인 계정 비밀번호를 쓰지 않기 위함
2. 메일플러그 관리자/사용자 설정에서 **SMTP 서버 주소·포트**와 외부 발송(SMTP) 허용 여부 확인
3. Vercel 환경변수: `SMTP_HOST`(서버 주소), `SMTP_PORT`(보통 465), `SMTP_USER`(발송 계정), `SMTP_PASS`(비밀번호), `SMTP_FROM`(예: `MICELEECH PMS <pms@miceleech.com>`)

## 6. 카카오워크 알림 (Bot)

1. 카카오워크 **관리자 페이지 → 봇 → 봇 만들기** (워크스페이스 관리자 권한 필요) → 이름 `MICELEECH PMS`
2. 발급된 **App Key** 를 Vercel 환경변수 `KAKAOWORK_BOT_KEY` 에 입력
3. 봇은 PMS 로그인 이메일(또는 '알림 설정'의 카카오워크 이메일)로 사용자를 찾아 1:1 메시지를 보냅니다

## 7. 알림 동작 확인

- 10분마다 발송함 처리, 매일 08:00(KST) 마감 D-1·D-DAY 알림 (`vercel.json` 크론)
- 설정하지 않은 채널은 발송하지 않고 대기합니다(설정 후 자동 발송)
- ⚠ Vercel 무료 요금제는 크론 실행 빈도가 제한될 수 있어 10분 주기는 Pro 요금제 기준입니다
