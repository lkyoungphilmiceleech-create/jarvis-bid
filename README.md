# jarvis-bid

조달청 나라장터 입찰공고를 매 평일 자동 수집하는 저장소입니다. Zapier 릴레이를 대체합니다.

## 구조

- `collect.py` — 나라장터 OpenAPI 34개 질의를 병렬 호출하고, 중복·오탐을 제거해 JSON으로 저장합니다.
- `.github/workflows/collect.yml` — 평일 09:40 KST 자동 실행. `request.json`을 수정해 커밋하면 즉시 재실행됩니다.
- `data/latest.json` — 가장 최근 수집 결과.
- `data/YYYY-MM-DD.json` — 날짜별 보관본.

## 필요한 Secret

| 이름 | 값 |
|---|---|
| `DATA_GO_KR_KEY` | data.go.kr 인증키(Decoding) |

## 수집 기준

집중 10개 기관은 키워드와 무관하게 전량 수집하고, 그 외 기관은 투자·상담·박람회·전시·홍보관·로드쇼·비즈매칭·비즈니스매칭·마켓·컨퍼런스 키워드로 걸러 수집합니다. 전기차 충전설비, 폐기·철거, 금융성 투자, 입시·심리 상담, 단순 시설관리는 오탐으로 자동 제외합니다.
